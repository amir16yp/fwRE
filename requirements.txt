#

#     installed, fwre extracts SquashFS itself and records real Unix mode bits /

#   jefferson   -> JFFS2  (provides the `jefferson` CLI)
#   ubi_reader  -> UBI/UBIFS (provides `ubireader_extract_files`)
#
# fwre works without them (7z handles the SquashFS/cramfs/ext majority); install
# these for perm-aware SquashFS and for JFFS2 / UBI-UBIFS images.
